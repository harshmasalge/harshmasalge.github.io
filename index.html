IITGN E-Journal Semantic Search

Natural-language discovery for the IITGN e-journals portal. Ask for “AI helping doctors” and get relevant journals, not keyword misses. Built entirely on free, open-source tools.

  • Encoded 10K+ academic journals into 384-dimensional embeddings with Sentence Transformers (all-MiniLM-L6-v2).

  • CI/CD pipeline with automated Bandit, Safety and TruffleHog security scans.

08Deep learning

Anomaly Detection on Tennessee Eastman Process

An LSTM autoencoder that learns normal industrial-process behaviour and flags faults from reconstruction error.

  • Stacked LSTM encoder-decoder in PyTorch over 50-timestep sliding windows of 52 process variables and 21 fault types.
  • Threshold set at mean + 3σ of validation reconstruction error; evaluated with ROC-AUC, precision/recall/F1 and detection delay.
  • Modular, reproducible pipeline: one command runs data loading, training, evaluation and six visualisation types.

Sleep Apnea Detection from Respiration Signals

A deep-learning pipeline that classifies breathing anomalies such as hypopneas and apneas from overnight sleep recordings.
